# Jorge Pereira — Portfólio

Site pessoal em HTML/CSS puro apresentando trabalho em marketing digital, tráfego pago e IA aplicada a vendas.

## Como usar

Abra o arquivo `index.html` diretamente no navegador — não precisa de instalação nem build.

## Publicar gratuitamente com GitHub Pages

1. Suba este arquivo (`index.html`) para o repositório.
2. Vá em **Settings → Pages**.
3. Em "Source", selecione a branch `main` e a pasta `/root`.
4. Salve. Em alguns minutos o site estará no ar em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

## Personalizar

- Textos de "Sobre" e "Serviços": edite diretamente dentro das tags `<p>` e `<h3>` do `index.html`.
- Link de contato: procure por `instagram.com/jorgeads2025` e troque pelo seu link atualizado, se mudar.
- Cores: no topo do arquivo, dentro de `:root`, estão as variáveis `--bg`, `--lime`, `--coral`, etc.
